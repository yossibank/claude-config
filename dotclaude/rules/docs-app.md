# アプリの文書

アプリのリポジトリの文書を読み書きする時に読み込まれる決まり。文書の役割と足す条件、決定と画面の仕様の形を決める。spec の中身の役割は、各リポジトリの `.claude/rules/` に書く。

## 書くこと

各文書は、次の役割だけを持つ。

| 文書 | 書く | 書かない |
| --- | --- | --- |
| README | 入口・機能の画面・全体像の図・実行環境・文書の一覧 | 機能の詳しい中身、決定、手順とコマンド（`docs/development.md`） |
| CLAUDE.md | 作業の進め方、このリポジトリだけのコードの書き方、作業と文書の対応 | 全リポジトリ共通の決まり（claude-config） |
| overview | 何を作るか、解決したい不満、最初のリリースの機能、守ることと未決 | 作り方 |
| architecture | 今の形（フォルダ、ターゲット、依存、署名の状態） | 理由、選ばなかった案、decisions の決定の言い直し |
| architecture-parts | 複数の画面で使う仕組みの名前、使いどころ、置き場所 | 仕組みの中身の説明 |
| decisions | 決定、理由、選ばなかった案 | 形の詳しい説明（architecture へリンク） |
| data | 表の形と、その決まり | なぜその形か |
| roadmap | 作る順番、状態、画面、この先の段階と収益化 | 設定・環境の状態 |
| glossary | 画面の言葉・文書の言葉・コードの型・意味の対応 | 決まりの説明 |

## 足す条件

最初は CLAUDE.md・README・`docs/overview.md`・`docs/roadmap.md` を作る。app-init は、`docs/architecture-parts.md` も置く。ほかの文書は、次の条件を満たした時に足す。

| 文書 | 足す条件 |
| --- | --- |
| `docs/decisions/<領域>.md` | 迷った案があり、理由を残さないと同じ議論になる決定が出た時 |
| `docs/architecture.md` | 構成が共通の形（claude-config の `docs/app/ios-architecture.md`）から外れた時。書くのは、外れた点と、ID などアプリだけの事実 |
| `docs/architecture-parts.md` | app-init が、土台の型の行を入れて置く。無いアプリは、複数の画面で使う仕組みを初めて足した時 |
| `docs/data.md` | データベースに表を持った時 |
| `spec/fixtures/` | 計算の決まりがあり、iOS と Android で同じ結果が要る時 |
| `spec/export-format.md` | ユーザーのデータを書き出す・読み込む時 |
| `docs/glossary.md` | 画面の言葉とコードの名前が食い違う語が出た時 |

## 決定の節の形

decisions の節は、次の決まりで書く。

| 部分 | 決まり |
| --- | --- |
| 決定 | 太字の 1 行にする。`**決定：` で探せるように、書き出しをそろえる |
| 表の形 | 見出しを `項目` と `内容` にし、1 列目を中央にそろえる |
| 理由 | 1 列目を `💡 理由` にし、却下の行より前に置く |
| 却下 | 1 列目を `❌ 却下` にし、1 案 1 行で書く。案の名前だけに取り消し線を引き、後ろに理由を書く |
| 理由の無い案 | 理由を今の文書や git の履歴から辿れない案は、行ごと消す。推測で理由を作らない |
| 計算 | 計算の決まりは、表の後に `$$` のブロックで書く |
| `[!IMPORTANT]` | その節で一番守るべき要点だけにする。2〜3 項目が目安で、8 項目までにする |
| 細かい決まり | `[!IMPORTANT]` に入らないものは、`###` の小見出しと表に移す |

```markdown
## 手元のお金と純資産

**決定：資産タブの合計は「手元のお金」と呼ぶ。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | カードのマイナスが資産のマイナスに見えない |
| ❌ 却下 | ~~「残高の合計」のまま~~ カードもマイナスで並び、使える額に見えない |
| ❌ 却下 | ~~合計を「純資産」と呼ぶ~~ 家や投資まで含む額と混ざる |
| 関連 | <リンク。無ければ行ごと消す> |

$$\text{手元のお金} = \text{手持ち} + \text{カードの残高}$$

> [!IMPORTANT]
> 純資産は投資か借入の口座がある時だけ出し、しまった財布は入れない。

### 資産と負債の欄

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 口座がある | 小見出しと小計 | 行を押すと編集 |
```

## 画面の仕様の形

画面の動きは、段落で書かずに、小見出しの下の状態・見た目・操作の表で書く。状態や絵文字だけの列は中央に、金額や数の列は右にそろえる。

スクリーンショットは、`make snapshot` の PNG を `docs/images/screens/<セット>/` に置く。表の後に `<picture>` でライトとダークを出し、幅は `width="280"` にする。

```markdown
| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 収まらない | 2 行目の端を薄くし ⌄ を重ねる | 押すと開く |
| 開いた | 全文と ⌃ | 押すと閉じる |
```
