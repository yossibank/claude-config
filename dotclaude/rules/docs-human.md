# 人が読む文書の形

README と `docs/`・`spec/` を読み書きする時に読み込まれる決まり。`docs-core.md` に足して、人が読む文書の見た目と README の組み立てを決める。

## 冒頭

タイトルの直後には、文書で分かることを書く。形は、文書で分ける。

| 文書 | 冒頭 |
| --- | --- |
| README | 何のリポジトリかの 1 文。続きは下の「README の形」に従う |
| `docs/`・`spec/` | `[!NOTE]` に分かることを書く。3 行までと関連文書のリンクにする |

## 見出しの絵文字

`##` の見出しの絵文字は、次の決まりで付ける。

| 決まり | 中身 |
| --- | --- |
| そろえる | すべての `##` の頭に 1 つずつ付けるか、どれにも付けない |
| 付ける文書 | README・`docs/`・`spec/` は付ける。節の多い `docs/decisions/` は、付けないでそろえてよい |
| 選び方 | 節の中身に近いものを、下の表から選ぶ |
| 重ねない | 1 つの文書の `##` で、同じ絵文字を 2 度使わない |

### 見出しの絵文字の表

節と絵文字は、次のように対応させる。

| 節 | 絵文字 |
| --- | --- |
| 全体像、構成 | `🗺️` |
| フォルダ | `📂` |
| パッケージ、モジュール | `📦` |
| 使う技術 | `🛠️` |
| 文書 | `📚` |
| 実行環境 | `💻` |
| 入れ方、使い方、動かし方 | `🚀` |
| 手順、足し方 | `🪜` |
| 決まり、書き方 | `📏` |
| 名前の付け方 | `🏷️` |
| 仕組み、フック | `🪝` |
| スキル、道具 | `🧰` |
| スクリプト | `📜` |
| エージェント | `👷` |
| 設定、環境変数 | `🔧` |
| 表示、見た目 | `🖥️` |
| 確認、テスト | `🧪` |
| 変更 | `📝` |
| ブランチ、PR | `🌿` |
| 画面 | `📱` |
| 機能 | `✨` |
| ウィジェット、拡張 | `🪟` |

## 本文の絵文字

本文の絵文字は、言葉と並べて 1 つだけ使う。次の表のものに限る。

| 分類 | 絵文字 |
| --- | --- |
| 状態 | `✅` 完了、`🚧` 作業中、`⬜` 未着手 |
| OS・役割 | `🍎` iOS、`🤖` Android、`🧩` 共通 |
| 重さ | `🔴` 高、`🟠` 中、`🟡` 低、`⚪` 無し |
| 呼ぶ人 | `🙋` 人が頼んだ時だけ、`🤝` 人と Claude、`🧠` Claude だけ |
| 仕組みの動き | `🛑` 止める、`💬` 知らせる、`🧹` 整える |
| 決定 | `💡` 理由、`❌` 却下、`📌` 決定 |

`💡` と `❌` は、decisions の理由と却下の行の 1 列目に付ける。`📌` は、索引の「決めたこと」のように決定を並べる表に付ける。節の `**決定：` の行には付けず、探す書き出しを変えない。

## 人が読む文書だけの表現

次の表現は、人が読む文書だけに使う。どの文書にも使える表現は、`docs-core.md` の「表現」にある。

| 表現 | 決まり |
| --- | --- |
| 理由と却下の表 | decisions の節に置く。形は `docs-app.md` の「決定の節の形」にある |
| 列のそろえ | 状態や絵文字だけの列は中央（`:---:`）、金額や数の列は右（`---:`）にそろえる |
| 状態の図 | 状態の移り変わりは Mermaid の `stateDiagram-v2` にし、`classDef` で色を分ける |
| 段の図 | roadmap の段の並びは `timeline` にし、進み具合は `gantt` か段の表のチェックボックスにする |
| チェックボックス | roadmap の段にある作業の、済みを `- [x]`、残りを `- [ ]` にする |
| 脚注 | `[^1]` で、出典や細かい補足を本文の外に出す。1 つの文書で 5 つまでにする |
| 数式 | 計算の決まりは `$$` のブロックにし、語は `\text{…}` で書く |
| キー | テンキーやキーの割り当ての仕様で、キーを `<kbd>` で囲む |
| 色見本 | テーマの色は、下の「色見本」の SVG で見せる |
| スクリーンショット | 画面の仕様に置く。置き場所と出し方は `docs-app.md` の「画面の仕様の形」にある |

状態の図の色は、失敗と警告を赤系、完了を緑系、途中を黄系にする。表で足りるものは図にしない。

```markdown
$$\text{純資産} = \text{手元のお金} + \text{投資} - \text{借入}$$

<kbd>7</kbd> <kbd>00</kbd> <kbd>⌫</kbd>
```

## 技術のアイコン

使う技術は、アイコンを並べた 1 枚の SVG で見せる。shields.io のバッジは使わない。

| 決まり | 中身 |
| --- | --- |
| 作り方 | `bin/docs-tech-icons.py` で `docs/images/tech.svg` を作る。ロゴは Simple Icons から取る |
| 並び | 対応 OS → 言語 → 主な技術。版は対応 OS と言語だけに書く |
| ロゴの無い技術 | 近いロゴを、その技術の色で使う |
| ストア | 公開したアプリは、App Store の公式のバッジの画像をストアのページにリンクする |

```sh
python3 -I ~/Applications/AI/claude-config/bin/docs-tech-icons.py docs/images/tech.svg apple:000000:iOS:18+ swift:F05138:Swift:6
```

## 色見本

テーマの色は、色の四角と名前・値を並べた 1 枚の SVG で見せる。

| 決まり | 中身 |
| --- | --- |
| 作り方 | `bin/docs-color-swatches.py` で `docs/images/` に SVG を作る |
| 色の渡し方 | 名前とライトの値を並べ、ダークの値があれば続ける |
| 列 | ダークの値を 1 つでも渡すと、ライトとダークの 2 列にする |

```sh
python3 -I ~/Applications/AI/claude-config/bin/docs-color-swatches.py docs/images/colors.svg 背景:FFFFFF:1C1C1E 文字:1C1C1E:F2F2F7
```

## README の形

リポジトリの直下とひな形の README は、表・図・画像で見せる。文は冒頭の 1 文だけにし、アラートは使わない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 冒頭 | タイトル、何のリポジトリかの 1 文、ストアのバッジ、技術のアイコン |
| 2 | 機能 | 画面のあるものは、見出しの行に機能の名前を、下の行にスクリーンショットを並べた表。画面の無いものは、部品とできることの表 |
| 3 | 全体像 | 構成と部品のつながりの図 |
| 4 | 実行環境 | 対応 OS・言語・開発の道具と版の表。手順とコマンドは書かず、`docs/development.md` に置く |
| 5 | 入れ方 | 道具とライブラリだけ。コマンドのコードブロックを置く |
| 6 | 文書 | docs の一覧の表 |
| 7 | 中身の節 | 用語、評価など、リポジトリごとの表 |
| 8 | そのほかの節 | フォントは、見本の画像を並べた表にする |

無い節は作らない。節の中に置けるものは、次のとおりである。

| 置ける | 置けない |
| --- | --- |
| 表・図・画像・コードブロック・箇条書き・リンクだけの行 | 文の段落、アラート |
