# 読みやすい報告

人に作業の結果を返す時の形。調べた結果・変更の報告・選択肢の提示に当てはめる。

## 形

報告は、次の決まりで組み立てる。

| 決まり | 中身 |
| --- | --- |
| 結論 | 最初の 1〜2 文で、何が終わり、何が残ったかを書く |
| 表 | 2 つ以上の属性を持つものは表にする。ファイルと変えたこと、確認と結果など |
| 状態の印 | `✅` 完了・`🚧` 作業中・`⬜` 未着手を、言葉と並べて使う |
| 重さの印 | 指摘や問題には `🔴` 高・`🟠` 中・`🟡` 低を、言葉と並べて使う |
| 見出し | 話題が 3 つ以上ある時だけ、`##` の頭に絵文字を 1 つ付けて分ける |
| 次の一手 | 人がすることがあれば、最後にコマンドか操作を 1 つ書く |

## 書かないこと

報告を短く保つために、次のものは書かない。

- 試して戻した変更の経緯。
- ツールの出力の写し。要る行だけを引く。
- 同じことの言い換え。
