# 文書の書き方

`.md` を読み書きするときに読み込まれる決まり。文書ごとの役割は、各リポジトリの CLAUDE.md か `.claude/rules/` にある。

> [!IMPORTANT]
> 文書には**今の状態だけ**を書く。経緯は git の履歴に任せる。

## 運用

次の決まりで、文書を今の状態に保つ。

| 決まり | 中身 |
| --- | --- |
| 書き換える | 事実が変わったら、その箇所を書き換える。末尾への追記や「以前は〜」で済ませない |
| 1 つの事実は 1 か所 | ほかの文書はリンクで指す。例外は README のバッジだけ |
| 書く前に探す | 事実を書く前に、同じ語を grep で探す。見つかったら書き足さず、そこへリンクする |
| 消す | 使わなくなった節・表の行・図は消す。空の見出しを残さない |
| 決まっていないこと | 「未決」と書く。決まったら書き換えて「未決」を消す |
| 確かめていないこと | `[!WARNING]` にまとめる。確かめたら本文に結果を書き、WARNING から消す |

## 文の書き方

次の決まりは、文化審議会「公用文作成の考え方」(2022) と、箇条書きの読みやすさの実験 (Campbell, 1999) に基づく。

| 決まり | 中身 |
| --- | --- |
| 結論を先に | 文書の最初の 1 文で、その文書に何があるかを書く |
| 一文を短く | 60 字を超えたら、句点で区切れないか見直す。一文の論点は 1 つにする |
| 見出し | 見出しだけを読めば内容がつかめる言葉にする。絵文字を付けない |
| 箇条書きの前置き | 箇条書きの前に、何の一覧かを 1 文で書く |
| 英数字 | 日本語と英数字の間に半角スペースを入れる |

## 表現の使い分け

内容に合わせて、次の表現を使い分ける。

| 表現 | 使う場面 | 使わない場面 |
| --- | --- | --- |
| 表 | 項目が 3 つ以上並ぶもの、比較 | 1〜2 項目なら文で書く。列が 1 つなら箇条書きにする |
| Mermaid の図 | 依存の向き、処理の流れ、表どうしの関係 | 表で足りるもの |
| フォルダの木 | フォルダ構成 | |
| アラート | `NOTE` 補足、`IMPORTANT` 守ること、`WARNING` 未検証・注意、`CAUTION` 壊れる・戻せない操作 | 本文の言い換え。1 節に 1 つまで |
| バッジ | README の、変わりにくい事実（対応 OS・言語の版） | 進み具合など、よく変わるもの |
| 状態の絵文字 | 進み具合の状態（✅ 完了、🚧 作業中、⬜ 未着手） | 見出し、本文の飾り |
| グラフ | 数値のデータがあるとき | 数値がないとき |
| 画像 | 使わない。AI が読めず、差分も見えない | |

## CLAUDE.md の形

各リポジトリの CLAUDE.md は、次の順に書く。無い節は作らない。

| 順 | 見出し | 中身 |
| --- | --- | --- |
| 1 | （見出しなし） | 何のリポジトリかを 1 文で |
| 2 | 作業の進め方 | 確認のコマンド、作業の手順 |
| 3 | コードの書き方 | このリポジトリだけの書き方 |
| 4 | 構成 | 置き場所の決まり、依存の向き |
| 5 | そのほかの節 | ほかのリポジトリとの取り決め、文書の役割など |

ここと共通の CLAUDE.md にある決まりは、各リポジトリに書かない。
