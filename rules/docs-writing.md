# 文書の書き方

`.md` を読み書きするときに読み込まれる決まり。運用と書き方、読み手ごとの形を決める。アプリの文書ごとの役割は `rules/docs-app.md` にある。

> [!IMPORTANT]
> 文書には**今の状態だけ**を書く。経緯は git の履歴に任せる。

## 運用

文書を今の状態に保つために、次の決まりを守る。

| 決まり | 中身 |
| --- | --- |
| 書き換える | 事実が変わったら、その箇所を書き換える。末尾への追記や「以前は〜」で済ませない |
| 1 つの事実は 1 か所 | ほかの文書はリンクで指す。例外は README のバッジだけ |
| 書く前に探す | 事実を書く前に、同じ語を grep で探す。見つかったら、そこへリンクする |
| 消す | 使わなくなった節・表の行・図は消す。空の見出しを残さない |
| 書かない | 外のツールの事情、決まりの言い換え |
| 決まっていないこと | 「未決」と書く。決まったら書き換えて「未決」を消す |
| 確かめていないこと | `[!WARNING]` にまとめる。確かめたら本文に結果を書き、WARNING から消す |

## 読み手で分ける

文書は、読み手で形を変える。どちらも、文字を並べるだけにせず、見出し・表・箇条書きで形を作る。

| 読み手 | 文書 | 形 |
| --- | --- | --- |
| Claude | CLAUDE.md、`rules/`、`SKILL.md`、`agents/` | 絵文字と飾りを使わない。決まった節の並びと表で読ませる |
| 人 | README、`docs/`、`spec/` | 見出しの絵文字、アラート、図、バッジで目立たせる |

## 文・見出し・用語

文・見出し・用語は、読み手によらず次の決まりで書く。

### 文

文は、短く区切って書く。

| 決まり | 中身 |
| --- | --- |
| 文体 | 常体（「である」「する」）で書く。敬体を混ぜない |
| 結論を先に | README 以外の人が読む文書は、タイトルの直後の `[!NOTE]` に分かることを書く |
| 結論の長さ | 冒頭の `[!NOTE]` は、3 行までと関連文書のリンクにする |
| 冒頭の 1 文 | そのほかの文書は、最初の 1 文で何があるかを書く |
| 一文を短く | 一文は 60 字までにし、超えたら句点で区切る。コードとパスも字数に数える |
| 段落と項目 | 1 つの段落と箇条書きの 1 項目は、3 文までにする |
| 表のセル | 表のセルは、2 文までにする。1 つのセルに別々の指示を入れない |
| 長い説明 | 3 文を超える説明は、手順なら番号付きの箇条書き、比べるものなら表にする |
| 一覧の前置き | 何の一覧か見出しで分かれば、前置きを書かない |
| 項目の数 | 一覧の前置きに、項目の数を書かない |
| 英数字 | 日本語と英数字の間に半角スペースを入れる |

### 見出し

見出しは、目で追うための言葉にする。

| 決まり | 中身 |
| --- | --- |
| 言葉 | 見出しだけで中身がつかめる言葉にする |
| 名前 | 同じ階層で同じ名前を使わない |
| 目次 | GitHub が作るので、手で書かない |
| 見出しの間 | 見出しと、そのすぐ下の小見出しの間に、1 文以上の本文を置く |

### 用語

用語は、文書とコードで同じものを指すようにそろえる。

| 決まり | 中身 |
| --- | --- |
| 言葉 | `docs/glossary.md` があれば、その言葉を使う |
| 型名 | 型がある語は、初めに型名を `コード` で添える |

## 表現

表現は、内容に合わせて次のように使い分ける。

| 表現 | 使う | 使わない |
| --- | --- | --- |
| 表 | 2 つ以上の属性を持つ項目の比較。書くことの無いセルは空にする | 単純な一覧 |
| 箇条書き | 単純な一覧、手順 | 1〜2 項目（文で書く） |
| Mermaid の図 | 依存の向き、処理の流れ、表どうしの関係、状態の移り変わり、画面の移動 | 表で足りるもの |
| グラフ | 数値のデータ。Mermaid の `xychart` か `pie` で描く | 数値がないとき |
| フォルダの木 | フォルダ構成。木には名前だけを書き、説明は表に分ける | ファイルの一覧だけのとき |
| 太字 | 決定・結論の 1 行。守らないと壊れることの短い語句 | 1 節に 2 か所以上。文全体 |
| 斜体 | なし | すべて |
| アラート | 本文から分けて目立たせたい注意。種類は下の表 | 本文の言い換え。冒頭の `[!NOTE]` を除いて 1 節に 2 つ以上 |
| 画像 | README の見た目の紹介、docs の画面の仕様。alt に要点を書く | Claude が読む文書。本文の代わり |
| HTML | 画像の並び（`<img>`・`<table>`・`<picture>`）。長い補足を畳む `<details>` | 中央寄せなど、見た目だけのもの。決定や決まりを畳む `<details>` |

### アラートの種類

アラートは、伝えることの重さで使い分ける。

| 種類 | 使う時 |
| --- | --- |
| `NOTE` | 補足 |
| `TIP` | こつ |
| `IMPORTANT` | 守らないといけないこと |
| `WARNING` | 危ないこと、確かめていないこと |
| `CAUTION` | 壊れる操作、戻せない操作 |

## Claude が読む文書の形

CLAUDE.md・rules・SKILL.md・agents は、飾りを使わずに、決まった並びで読ませる。

| 決まり | 中身 |
| --- | --- |
| 飾り | 絵文字と画像を使わない |
| 冒頭 | タイトルの直後の 1 文で、読み込まれる時と決めることを書く |
| 決まり | 守ることは表か箇条書きにし、例はその後のコードブロックに置く |
| コマンド | 文の中に長いコマンドを書かない。コードブロックに出し、文では名前で呼ぶ |
| 手順の文末 | 番号付きの手順の項目は、「。」で終える |

### SKILL.md の節

SKILL.md の `##` は、次の順に並べる。中身の無い節は作らない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 起動条件 | description で足りない、使う時と使わない時 |
| 2 | 入力 | 引数と、決まっている前提 |
| 3 | 手順 | 番号付きの手順と、走らせるコマンド |
| 4 | 手順の詳細 | スクリプトがすること、出力の読み方など。名前は下の表に従う |
| 5 | 報告 | 人に返すもの |
| 6 | 制約 | してはいけないこと、必ずすること |

手順の詳細の節は、次の決まりで置く。「手順」と「報告」は、どの SKILL.md にも置く。

| 決まり | 中身 |
| --- | --- |
| 見出しの深さ | 手順の詳細は `##` にし、「手順」と「報告」の間に置く |
| スクリプトの節 | 名前は「<スクリプト> がすること」か「<スクリプト> の出力」にする |
| 出力の読み方 | 出力や画像をどう読むかの節は、「出力の読み方」にする |
| 制約の置き場所 | 禁止と必須の決まりは、本文に散らさず「制約」に集める |

### agents の節

agents の `##` は、次の順に並べる。中身の無い節は作らない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 観点 | 見ることと、見ないこと |
| 2 | 進め方 | 読み方、使うコマンド、してはいけないこと |
| 3 | 返す形 | 返すものと、その長さ。最後の節にする |

frontmatter には、次の項目を書く。

| 項目 | 中身 |
| --- | --- |
| `name` | ファイル名と同じ名前 |
| `description` | 使う時と使わない時 |
| `model` | 使うモデル。省かない |
| `tools` | 使える道具。書き換えないエージェントは、Edit と Write を入れない |

## CLAUDE.md の形

各リポジトリの CLAUDE.md は、次の順に書く。無い節は作らない。

| 順 | 見出し | 中身 |
| --- | --- | --- |
| 1 | 見出しなしの冒頭 | 何のリポジトリかを 1 文で |
| 2 | 作業の進め方 | 確認のコマンド、作業の手順 |
| 3 | コードの書き方 | このリポジトリだけの書き方 |
| 4 | 構成 | 置き場所の決まり、依存の向き |
| 5 | そのほかの節 | ほかのリポジトリとの取り決め、リポジトリだけの文書の役割など |

ここと共通の CLAUDE.md にある決まりは、各リポジトリに書かない。

## 人が読む文書の飾り

README と `docs/`・`spec/` は、見出しと絵文字で目で追える形にする。

### 見出しの絵文字

`##` の見出しの絵文字は、次の決まりで付ける。

| 決まり | 中身 |
| --- | --- |
| そろえる | すべての `##` の頭に 1 つずつ付けるか、どれにも付けない |
| README | 付ける |
| 選び方 | 節の中身に近いものを、下の表から選ぶ |

節と絵文字は、次のように対応させる。

| 節 | 絵文字 |
| --- | --- |
| 全体像、構成 | `🗺️` |
| 文書 | `📚` |
| 動かし方、入れ方、使い方 | `🚀` |
| 決まり、書き方 | `📏` |
| 名前の付け方 | `🏷️` |
| 仕組み、フック | `🪝` |
| スキル、道具 | `🧰` |
| スクリプト | `📜` |
| エージェント | `👷` |
| 設定、環境変数 | `🔧` |
| 確認、テスト | `🧪` |
| 画面 | `📱` |
| データ | `🗄️` |
| 注意 | `⚠️` |
| 目的 | `🎯` |
| 不満 | `😣` |
| 収益 | `💰` |
| 未決 | `❓` |
| 順番 | `🗓️` |

### 本文の絵文字

本文の絵文字は、言葉と並べて 1 つだけ使う。次の表のものに限る。

| 分類 | 絵文字 |
| --- | --- |
| 状態 | `✅` 完了、`🚧` 作業中、`⬜` 未着手 |
| OS・役割 | `🍎` iOS、`🤖` Android、`🧩` 共通 |
| 重さ | `🔴` 高、`🟠` 中、`🟡` 低、`⚪` 無し |

### バッジの並び

バッジは shields.io で作り、状態と技術の段に分けて並べる。段の間は空行で分け、無い段は作らない。

| 段 | 並び | 書き方 |
| --- | --- | --- |
| 状態 | CI → リリース → ライセンス | 動的なバッジ。CI は `label=Verify&logo=github` を付ける |
| 技術 | 対応 OS → 言語 → 主な技術 | 固定のバッジ。版は対応 OS と言語だけに書く |

技術のバッジは、次の決まりで作る。

- Simple Icons のロゴとブランドの色を付ける。
- `logoColor=white` にする。ロゴが無い技術は、近いロゴを使う。
- 技術の一覧を、バッジとは別に文字で並べない。

## README の形

README は、次の順に書く。無い節は作らない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 冒頭 | タイトル、何のリポジトリかの 1 文、バッジ、スクリーンショット |
| 2 | 全体像 | 構成と、部品のつながり |
| 3 | 動かし方 | 要る道具とコマンド。設定は「入れ方」、ライブラリは「使い方」 |
| 4 | 文書 | docs の一覧 |
| 5 | 中身の節 | 用語、評価など、リポジトリごとの説明 |
| 6 | そのほかの節 | リリース、出典など |

## 守らせる仕組み

決まりのうち文字で分かるものは、仕組みで止める。

| 仕組み | 走る時 |
| --- | --- |
| `hooks/docs-check.py` | `.md` を Edit・Write した後のフック |
| `scripts/config-audit.py` | `make audit` |

それぞれが見る決まりは、次のとおりである。ここに無い決まりは、仕組みでは見ていない。

| 仕組み | 見ること |
| --- | --- |
| `hooks/docs-check.py` | 一文の長さ、段落・項目・表のセルの文の数、一覧の前置きの項目の数 |
| `hooks/docs-check.py` | 見出しの絵文字の数と位置、`##` の絵文字のそろえ方（README は付ける） |
| `hooks/docs-check.py` | 見出しと小見出しの間の本文 |
| `hooks/docs-check.py` | Claude が読む文書の絵文字・本文の絵文字の表・斜体・日本語と英数字の間 |
| `hooks/docs-check.py` | README と `docs/` の外の HTML、使ってよいタグ、`docs/` の 1 ファイルの大きさ |
| `scripts/config-audit.py` | SKILL.md の「手順」と「報告」の有無、固定の節の順、ほかの節の置き場所 |
| `scripts/config-audit.py` | SKILL.md の description の文末と字数 |
| `scripts/config-audit.py` | agents の `name`・`model` と最後の「返す形」、rules の `paths` |
| `scripts/config-audit.py` | skills・agents・rules・hooks・scripts が README の表にあるか。リンク先があるか |
| `scripts/config-audit.py` | 追跡している全 `.md` に、`docs-check.py` と同じ検査をかける |
