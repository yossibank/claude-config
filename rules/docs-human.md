# 人が読む文書の形

README と `docs/`・`spec/` を読み書きするときに読み込まれる決まり。`docs-writing.md` に足して、見出しの絵文字・バッジ・README の節の順を決める。

## 見出しの絵文字

`##` の見出しの絵文字は、次の決まりで付ける。

| 決まり | 中身 |
| --- | --- |
| そろえる | すべての `##` の頭に 1 つずつ付けるか、どれにも付けない |
| README | 付ける |
| 選び方 | 節の中身に近いものを、下の表から選ぶ |

### 見出しの絵文字の表

節と絵文字は、次のように対応させる。

| 節 | 絵文字 |
| --- | --- |

| フォルダ | `📂` |
| パッケージ、モジュール | `📦` |

| 文書 | `📚` |
| 動かし方、入れ方、使い方 | `🚀` |
| 決まり、書き方 | `📏` |
| 名前の付け方 | `🏷️` |
| 仕組み、フック | `🪝` |
| スキル、道具 | `🧰` |
| スクリプト | `📜` |
| エージェント | `👷` |
| 設定、環境変数 | `🔧` |
| 表示、見た目 | `🖥️` |
| 確認、テスト | `🧪` |
| 変更 | `📝` |
| 画面 | `📱` |
| ウィジェット、拡張 | `🪟` |

## 本文の絵文字

本文の絵文字は、言葉と並べて 1 つだけ使う。次の表のものに限る。

| 分類 | 絵文字 |
| --- | --- |
| 状態 | `✅` 完了、`🚧` 作業中、`⬜` 未着手 |
| OS・役割 | `🍎` iOS、`🤖` Android、`🧩` 共通 |
| 重さ | `🔴` 高、`🟠` 中、`🟡` 低、`⚪` 無し |
| 呼ぶ人 | `🙋` 人が頼んだ時だけ、`🤝` 人と Claude、`🧠` Claude だけ |
| 仕組みの動き | `🛑` 止める、`💬` 知らせる、`🧹` 整える |
| 文脈の量 | `🟢` 半分まで、`🟡` 8 割まで、`🔴` 8 割を超えた |

## バッジの並び

バッジは shields.io で作り、状態と技術の段に分けて並べる。段の間は空行で分け、無い段は作らない。

| 段 | 並び | 書き方 |
| --- | --- | --- |
| 状態 | CI → リリース → ライセンス | 動的なバッジ。CI は `label=Verify&logo=github` を付ける |
| 技術 | 対応 OS → 言語 → 主な技術 | 固定のバッジ。版は対応 OS と言語だけに書く |

技術のバッジは、次の決まりで作る。

- Simple Icons のロゴとブランドの色を付ける。
- `logoColor=white` にする。ロゴが無い技術は、近いロゴを使う。
- 技術の一覧を、バッジとは別に文字で並べない。

## README の形

README は、次の順に書く。無い節は作らない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 冒頭 | タイトル、何のリポジトリかの 1 文、バッジ、スクリーンショット |
| 2 | 全体像 | 構成と、部品のつながり |
| 3 | 動かし方 | 要る道具とコマンド。設定は「入れ方」、ライブラリは「使い方」 |
| 4 | 文書 | docs の一覧 |
| 5 | 中身の節 | 用語、評価など、リポジトリごとの説明 |
| 6 | そのほかの節 | リリース、出典など |
