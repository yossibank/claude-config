# Claude が読む文書の形

Claude が読む文書を読み書きするときに読み込まれる決まり。CLAUDE.md・rules・SKILL.md・agents・output-styles に当たる。`docs-writing.md` に足して、飾らない形と節の並びを決める。

## 共通の形

Claude が読む文書は、飾りを使わずに、決まった並びで読ませる。

| 決まり | 中身 |
| --- | --- |
| 飾り | 絵文字と画像を使わない。出力に付ける印を、コードで示すのはよい |
| 冒頭 | タイトルの直後の 1 文で書く。rules は読み込まれる時と決めること、SKILL.md と agents はすることを書く |
| 決まり | 守ることは表か箇条書きにし、例はその後のコードブロックに置く |
| コマンド | パス・`${`・`git` などのコマンド名で始まり、空白を含む 40 字を超えるものは文の中に書かない。コードブロックに出し、文では名前で呼ぶ |
| 手順の文末 | 番号付きの手順の項目は、「。」で終える |

## SKILL.md の節

SKILL.md の `##` は、次の順に並べる。「手順」と「報告」はどの SKILL.md にも置き、ほかの中身の無い節は作らない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 起動条件 | description で足りない、使う時と使わない時 |
| 2 | 入力 | 引数と、決まっている前提 |
| 3 | 手順 | 番号付きの手順と、走らせるコマンド |
| 4 | 手順の詳細 | スクリプトがすること、出力の読み方など。いくつ置いてもよい |
| 5 | 報告 | 人に返すもの |
| 6 | 制約 | してはいけないこと、必ずすること |

手順の詳細の節は、次の決まりで置く。表に名前の無い節は、中身を表す名前にする。

| 決まり | 中身 |
| --- | --- |
| 見出しの深さ | 手順の詳細は `##` にし、「手順」と「報告」の間に置く |
| スクリプトの節 | 名前は「<スクリプト> がすること」か「<スクリプト> の出力」にする |
| 出力の読み方 | 出力や画像をどう読むかの節は、「出力の読み方」にする |
| 制約の置き場所 | 禁止と必須の決まりは、本文に散らさず「制約」に集める |

## agents の節

agents の `##` は、次の順に並べる。中身の無い節は作らない。

| 順 | 節 | 中身 |
| --- | --- | --- |
| 1 | 観点 | 見ることと、見ないこと |
| 2 | 進め方 | 読み方、使うコマンド、してはいけないこと |
| 3 | 返す形 | 返すものと、その長さ。最後の節にする |

frontmatter には、次の項目を書く。

| 項目 | 中身 |
| --- | --- |
| `name` | ファイル名と同じ名前 |
| `description` | 使う時と使わない時 |
| `model` | 使うモデル。省かない |
| `tools` | 書き換えないエージェントは必ず書き、Edit・Write・MultiEdit・NotebookEdit を入れない。書き換えるエージェントは省いてよく、省くと全部の道具を使える |

## CLAUDE.md の形

各リポジトリの CLAUDE.md は、次の順に書く。無い節は作らない。

| 順 | 見出し | 中身 |
| --- | --- | --- |
| 1 | 見出しなしの冒頭 | 何のリポジトリかを 1 文で |
| 2 | 作業の進め方 | 確認のコマンド、作業の手順 |
| 3 | コードの書き方 | このリポジトリだけの書き方 |
| 4 | 構成 | 置き場所の決まり、依存の向き |
| 5 | そのほかの節 | ほかのリポジトリとの取り決め、リポジトリだけの文書の役割など |

ここと共通の CLAUDE.md にある決まりは、各リポジトリに書かない。
