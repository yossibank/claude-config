# トークンの使い方を振り返る

`~/.claude/projects/` の会話の記録から、会話ごとに使ったトークンを集め、重い順に並べる手順。月の初めに、前の月の分を見る。

## 使い方

表は、次のコマンドで出す。件数を省くと 10 件である。

```sh
python3 -I ${CLAUDE_SKILL_DIR}/scripts/tokens.py <YYYY-MM> [件数]
```

会話は、始まった日（日本時間）の月に数える。記録の置き場所は `CLAUDE_PROJECTS` で変えられる。

## 表の列

表の列は、次のとおりである。

| 列 | 中身 |
| --- | --- |
| 日付 | 会話を始めた日 |
| 場所 | 会話を始めたリポジトリと、`@` の後に会話の中で一番多く使ったブランチ |
| 作業 | 会話の題 |
| 要求 | モデルへの要求の回数 |
| 入力換算 | 入力の値段に合わせて重みを付けて足した量。キャッシュの書き込みは 1.25 倍（5 分）か 2 倍（1 時間）、読み込みは 0.1 倍、出力は 5 倍にする。サブエージェントの分も含む。モデルごとの単価の差は入れていない |
| サブエージェント | 入力換算のうち、サブエージェントの割合 |
| 文脈の平均 | 1 回の要求で読ませた文脈の平均 |
| 出力 | 出力のトークン |

## 読み方

上位の作業ごとに、どこで重くなったかを次の表で見当を付ける。

| 見えること | 疑うこと | 効く決まり |
| --- | --- | --- |
| 文脈の平均が大きい | 区切らずに長く続けた。大きなファイルを丸ごと読んだ | `/ctx-handoff` と `/clear` で区切る。`docs-section.sh` で節だけ読む |
| 要求が多い | 1 つの会話で、関心事をいくつも扱った | PR を作ったら `/ctx-handoff` と `/clear` で区切る |
| 出力が多い | 長い報告や、同じ内容の書き直しを繰り返した | PR の本文は 1 回だけ書き直す |
| サブエージェントが 0% で重い | 広い探索を自分でした | 広い探索は `explorer` に任せる |

人には、表と、上位 3 件の見立てを返す。決まりの直しは提案に留め、人が決めてから直す。
