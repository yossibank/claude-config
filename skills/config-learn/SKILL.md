# 手直しから決まりを直す

人の手直しを材料に、決まりの改定案を出す手順。同じ指摘を 2 回受けないように、指摘を決まりか仕組みに移す。

## 材料

材料は、次のコマンドで集める。

```sh
python3 -I ${CLAUDE_SKILL_DIR}/scripts/collect.py <YYYY-MM>
```

`collect.py` は、次の材料を出す。

- `~/.claude/projects/*/memory/` の、種類が `feedback` のメモリ
- その月の会話で人が送った、400 字以下の文。手直しの言葉（「ではなく」「外して」「戻して」「毎回」など）を含むものだけを出す。1 件は、その言葉の前後 120 字に切る

## 手順

改定案は、次の順に作る。

1. 材料を仕分ける。アプリの機能や見た目への注文は外し、Claude の作り方・書き方・進め方への手直しだけを残す。
2. 残ったものを、同じ指摘ごとにまとめる。
3. まとまりごとに、今の決まりを探す。探す先は、claude-config の CLAUDE.md・`rules/`・`skills/`・`agents/` と、アプリの CLAUDE.md・`.claude/rules/` である。
4. 下の表で、案の種類を決める。
5. 案を人に見せ、選んでもらう。
6. 選ばれた案だけを、作業の区切りで直す。決まりに移したメモリは消す。

| 今の決まり | 指摘の回数 | 案 |
| --- | --- | --- |
| 無い | 2 回以上か、feedback のメモリがある | 決まりを足す。どのアプリでも同じなら claude-config、アプリだけならアプリのリポジトリ |
| 無い | 1 回 | 案にしない。次の月にまた見る |
| ある | 1 回以上 | 決まりが守られていない。文を短く強くするか、フックやスクリプトで止める仕組みにする。重なるメモリも消す |
| ある（メモリと重なる） | 0 回 | メモリを消す案にする |

メモリが、名前の変わったファイルや無くなった決まりを指している時は、直すか消す案にする。

## 報告

人には、次の形の表で返す。案は 5 件までにし、指摘の回数が多い順に並べる。

| 案 | 種類 | 直す先 | 根拠 |
| --- | --- | --- | --- |
| 決まりの文の案 | 足す・強める・仕組みにする・メモリを消す | ファイルのパス | 指摘の日付と回数、メモリの名前 |
