# 引き継ぎメモを書く

リポジトリの `.claude/handoff.md` を書き換える手順。続きのセッションは、会話の履歴を読まずに再開できる。続きのセッションでの読み方は、共通の CLAUDE.md の「使う量を抑える」にある。

## 手順

メモは、次の順に書く。

1. `.claude/handoff.md` を、下の「メモの形」で書き換える。
2. メモが 20 行を超えていないかを確かめる。超えていたら削る。
3. 報告する。

## メモの形

見出しは `# 引き継ぎ` の 1 つだけにする。その下に、次の項目を `- 目的：…` の形で 1 行ずつ並べる。中身の無い項目は書かない。

| 項目 | 書くこと |
| --- | --- |
| 目的 | 何を終えれば完了か |
| 決めたこと | 理由が要るものだけ。1 項目 1 行 |
| 次 | 次にすることを、する順に番号を付けて |
| 触ったファイル | パスだけ |
| 未検証 | 確かめていないこと |

## 報告

書いたら、次のとおり報告する。

- メモのパスと行数を書く。
- `/clear` で区切るよう勧める。

## 制約

- 試して戻した変更の経緯と、コードの中身の写しは書かない。
- `.claude/handoff.md` は、リポジトリの `.gitignore` に入れておく。
