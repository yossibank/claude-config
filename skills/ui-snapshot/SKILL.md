# 見た目を描いて確かめる

SwiftUI のビューを `ImageRenderer` で PNG に描き、見た目を確かめる手順。アプリを起動して画面を開かなくても、場合ごとの見た目を並べて比べられる。

## 手順

描く時は、次の順に進める。

1. 描く場合のセットを用意する。無ければ、下の「セット」に従って作る。
2. `render-snapshots.sh` を実行する。シミュレーターは、`CC_UI_DEVICE` に UDID を渡して選べる。渡さない時は、使える iPhone の最初の 1 台を使う。
3. 描いた PNG を、下の「出力の読み方」に従って読む。

```sh
${CLAUDE_SKILL_DIR}/scripts/render-snapshots.sh <パッケージのフォルダ> <セットのフォルダ> <出力先のフォルダ>
```

## render-snapshots.sh がすること

`render-snapshots.sh` は、次を行い、終わると必ずパッケージを元に戻す。

1. パッケージを `.git` を除いて一時のフォルダに退避し、そのパスを `退避:` の行に出す。
2. その場の Package.swift に、一時のテストのターゲット `UISnapshotTests` を足す。
3. セットに `patch.py` があれば、パッケージのフォルダを渡して走らせる。
4. 出力先の古い PNG を消し、セットの `SnapshotTests.swift` を入れる。
5. シミュレーターで、そのテストだけを動かす。
6. テストが通れば、描いた PNG の一覧を出す。通らなければ `NG` の行を出して止まる。

終わると、テストやパッチが足したファイルも消して、退避の状態に戻す。

## セット

セットは、描く場合をまとめたフォルダである。アプリのリポジトリの `.claude/snapshots/<名前>/` に置く。中のファイルは、次のとおりである。

| ファイル | 要る時 | 中身 |
| --- | --- | --- |
| `SnapshotTests.swift` | いつも | 描く場合と大きさ。出力先は `__OUT__` と書き、`render-snapshots.sh` が置き換える |
| `targets.txt` | いつも | テストが依存するターゲットを、1 行に 1 つ書く。ほかのパッケージの製品は `<製品>:<パッケージ>` |
| `patch.py` | 外から渡せない値を差し替える時 | 引数のパッケージのフォルダの中を書き換える。`@Environment(\.widgetFamily)` を引数に変えるなど |

新しいセットは、`${CLAUDE_SKILL_DIR}/templates/screen/` を写して作る。画面の大きさと、ライト・ダークの 2 つを描く形になっている。

## 描いた見た目の限り

`ImageRenderer` はウィンドウの外で描くので、次は実際の画面と違う。

- UIKit を元にした部品（`List`・`TextField`・`Map` など）は描かれないか、空になる
- ウィジェットの背景（`containerBackground`）と、ロック画面の色づけは描かれない
- 起動時に登録するフォントは、テストの中では登録されないので出ない

これらは、シミュレーターで画面を開いて確かめる。動きは `ui-record` で確かめる。

## 出力の読み方

PNG は、確かめたい場合のものだけを読む。全部を読まない。直す前と後を比べる時は、同じ場合のファイルを並べて読む。

## 報告

人には、描いた場合の数と、確かめた見た目のずれを返す。直した時は、直す前と後の同じ場合を並べて示す。

## 制約

- 出力先には、空のフォルダか、前に書いたフォルダ（`.ui-snapshot` がある）を渡す。ほかのフォルダは、中の PNG を消さないように `NG` で止まる。
- 走っている間は、パッケージのファイルを変えない。終わると退避から書き戻すので、その間の変更は上書きされる。
- 強制終了などで戻らなかった時は、`退避:` のフォルダから戻すか、git で戻す。
