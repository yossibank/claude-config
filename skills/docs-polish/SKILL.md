# 人が読む文書を見やすくする

人が読む文書を読み、文字だけが続く所を表・図・箇条書きに組み直す手順。形の決まりは `rules/docs-writing.md` と `rules/docs-human.md` に従う。

## 起動条件

人が README や docs を読みやすくしたいと頼んだ時と、文書を大きく書き足した後に使う。CLAUDE.md・rules・SKILL.md・agents の、Claude が読む文書には使わない。

## 入力

| 入力 | 中身 |
| --- | --- |
| `$ARGUMENTS` | 見るファイルかフォルダ。省いたら、リポジトリの根の `.` を渡す |

## 手順

見つける・案を出す・直すの順に進め、直す前に人の承認を得る。

1. `check-layout.py` で、文字だけが続く節を探す。
2. 当たった節と、文書全体を読み、「直し方の選び方」から形を選ぶ。
3. 案を、今の形と直した形を並べた見本で出す。1 つの案は 1 つの節にする。
4. 人の承認を得る。
5. 承認された案だけを直す。事実は変えず、形だけを変える。
6. 直した文書に `check-layout.py` をかけ直し、リポジトリの確認のコマンドを通す。

スクリプトは、次の形で呼ぶ。

```sh
python3 -I ${CLAUDE_SKILL_DIR}/scripts/check-layout.py <ファイルかフォルダ>…
```

## check-layout.py の出力

`check-layout.py` は、`##` 以下の節ごとに、表・箇条書き・図・アラートの無い文の行を数える。最初の `##` より前の冒頭は数えない。

| 出力 | 中身 |
| --- | --- |
| `NG <パス>:<行> <見出し>: …` | 文が 4 行以上続き、表・箇条書き・図・アラートが無い節 |
| `OK <パス>` | 当たる節の無い文書 |

フォルダを渡すと、その下の README・`docs/`・`spec/` の `.md` を見る。

## 直し方の選び方

文の中身に合わせて、次の形を選ぶ。

| 中身 | 形 |
| --- | --- |
| 2 つ以上の属性を持つものの比べ合い | 表 |
| 手順 | 番号付きの箇条書き |
| 処理の流れ、依存の向き、状態の移り変わり | Mermaid の図 |
| 数値の並び | Mermaid の `xychart` か `pie` |
| 守らないと壊れること | `[!IMPORTANT]` か `[!CAUTION]` のアラート |
| 状態・重さ・OS | `rules/docs-human.md` の本文の絵文字 |
| 節の見出し | `rules/docs-human.md` の見出しの絵文字 |

## 報告

手順の 3 と、直した後に、次を返す。

| 時 | 返すもの |
| --- | --- |
| 3 | 当たった節の数と、案ごとの見本 |
| 直した後 | 直した節、`check-layout.py` の結果、通した確認 |

## 制約

- 4 の承認の前に、文書を書き換えない。
- 事実・数値・決まりの中身を変えない。形だけを変える。
- 決まりの表に無い絵文字を使わない。要る時は、先に `rules/docs-human.md` の表に行を足す案を出す。
